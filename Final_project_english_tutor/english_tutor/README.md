# 유아용 사물 인식 영어 선생님 (Jetson Orin Nano)

카메라로 사물을 보고(YOLO), 아이가 "이게 뭐야?"라고 음성으로 물으면(Whisper) Gemma가 그 사물의 영어 단어와 쉬운 설명을 만들고, Piper가 음성으로 읽어 주는 Vision-LLM 융합 시청각 멀티모달 시스템입니다. 모든 모델은 Jetson 안에서 인터넷 없이 로컬로 실행됩니다.

## 파일 구조 (필수)

* `main.py`: 프로그램 실행 파일. 카메라+YOLO(메인 스레드), 음성 듣기(음성 스레드), 수업 생성·말하기(수업 스레드)를 실행하고 화면 표시와 키 입력(`l`, `q`)을 처리
* `config.py`: 모델 경로, 마이크/스피커 장치, 녹음 시간, YOLO 신뢰도, Gemma 설정 등 모든 설정값 (환경 변수로 덮어쓰기 가능)
* `objects.py`: YOLO(COCO) 클래스 이름 → (영어 단어, 한국어 이름) 사전. 아이에게 위험한 물건(칼, 가위)은 제외
* `vision.py`: YOLO 탐지(`Detector`), 여러 사물 중 아이가 보여주는 것 선택(`pick_main_object`), 최근 프레임 기준 안정화(`StableTarget`), 화면 표시(`draw`)
* `audio.py`: 음성 입출력. `arecord` 녹음 + `whisper.cpp` STT, 무음 감지, "이게 뭐야?" 질문 판별, Piper TTS(한국어/영어 목소리 분리) + `aplay` 재생
* `tutor.py`: Gemma(llama.cpp)로 영어 예문과 쉬운 한국어 설명 생성, 출력 형식 검증과 기본 문장 대체, 수업 결과 JSON 캐시
* `setup_models.sh`: 영어 TTS 목소리(Piper `en_US-lessac-medium`) 다운로드 및 폴더 준비
* `selftest.py`: 카메라·마이크·Jetson 없이 돌릴 수 있는 로직 테스트 (질문 판별, 출력 파싱, 폴백, 캐시)
* `requirements.txt`: 필요한 Python 패키지 목록
* `README.md`: 이 문서
* (실행 중 자동 생성) `~/vision-llm/src/json/lesson_cache.json`: 한 번 만든 수업 저장 파일
* (실행 중 자동 생성) `~/vision-llm/src/audio/*.wav`: 녹음/음성 출력 임시 파일

## 실행 방식 (필수)

**1. 사전 준비**

수업에서 만든 `~/vision-llm` 환경을 그대로 사용합니다. (YOLO TensorRT engine, Gemma GGUF, `whisper.cpp`, Piper 가상환경 `.piper_venv`, 한국어 Piper 목소리)

```bash
# 이 폴더를 ~/vision-llm/english_tutor/ 로 복사한 뒤
cd ~/vision-llm/english_tutor
bash setup_models.sh                  # 영어 Piper 목소리 다운로드 (처음 1회)
```

**2. 마이크 번호 설정**

```bash
arecord -l                            # card 번호 확인 (예: card 2, device 0)
export MIC_DEVICE=plughw:2,0          # 또는 config.py 24줄의 기본값 수정
```

**3. 실행**

```bash
python selftest.py                    # (선택) 하드웨어 없이 로직 테스트
python main.py --dry-run --no-voice   # 1단계: 소리/마이크 없이 카메라+Gemma만 확인 ('l' 키)
python main.py                        # 2단계: 전체 실행 (음성 질문)
```

| 옵션 | 설명 |
|---|---|
| `--no-voice` | 마이크를 끄고 `l` 키로만 질문 |
| `--dry-run` | 소리 없이 텍스트만 출력 (디버깅용) |
| `--headless` | 영상 창 없이 실행 (SSH 접속 시) |

**4. 사용 방법**

* 카메라 앞에 책, 컵, 곰 인형 같은 물건을 보여 주고 "이게 뭐야?"라고 말합니다.
* 영상 창에서 `l` 키를 누르면 음성 대신 수동으로 질문할 수 있습니다. (부모용/테스트용)
* 종료: 영상 창에서 `q` 키, 또는 터미널에서 `Ctrl+C`

**5. 동작 순서**

[한국어 힌트 + 영어 단어] ➔ [영어 문장] ➔ [한국어 마무리 멘트] ➔ [1초 대기]

**6. 자주 쓰는 설정** (`config.py` 또는 환경 변수)

| 설정 | 용도 |
|---|---|
| `MIC_DEVICE`, `SPEAKER_DEVICE` | 마이크/스피커 장치 번호 |
| `USE_PASUSPENDER` | `pasuspender` 오류가 나면 `0` |
| `RECORD_SECONDS`, `SILENCE_RMS` | 녹음 시간, 조용하다고 판단하는 음량 기준 (인식이 안 되면 낮추기) |
| `YOLO_CONF` | 사물 탐지 신뢰도 기준 |
| `CONTEXT_WINDOW` | Gemma 컨텍스트 크기 (Jetson 메모리 절약을 위해 1024) |

## 창의성 및 확장성 (프로젝트에만 해당)

**아이디어 설명**

* 아이가 궁금해하는 바로 그 순간("이게 뭐야?")에 눈앞의 실제 사물로 영어를 알려 주는 유아용 에듀테크입니다.
* 카메라(Vision), 음성 인식(STT), 언어 모델(LLM), 음성 합성(TTS)을 하나로 이어 아이가 글을 읽거나 화면을 조작하지 않고 말로만 사용할 수 있습니다.
* 인터넷 연결이 필요 없어 아이의 음성과 영상이 외부로 나가지 않습니다.

**구현한 내용**

* **보기:** YOLO가 책, 컵, 곰 인형, 공 등 31종의 사물을 탐지하고, 화면 중앙에 가깝고 큰 사물을 아이가 보여주는 물건으로 선택합니다. 최근 12프레임 중 5번 이상 같은 사물이 선택되어야 "확실히 보임"으로 판단해 깜빡임으로 인한 오답을 막습니다.
* **듣기:** `arecord`로 녹음한 뒤 조용하면 STT를 건너뛰고(속도·오인식 방지), Whisper 결과에서 "뭐/뭔/무엇/what" 등 질문 패턴이 있을 때만 수업을 시작합니다.
* **생각하기:** 영어 단어는 `objects.py` 사전에서 확정하고 Gemma는 예문과 쉬운 설명만 생성합니다. 출력은 `EN:` / `KO:` 두 줄 형식으로 고정하며, 형식이 어긋나거나 단어가 빠지면 "This is a cup." 같은 기본 문장으로 대체합니다. 이모지·마크다운은 TTS가 그대로 읽지 않도록 제거합니다.
* **말하기:** 한국어 문장은 한국어 Piper 목소리, 영어 단어와 문장은 영어 Piper 목소리로 따로 읽어 발음을 살리고, 영어는 천천히 두 번 반복합니다.
* **안정적인 실시간 구조:** 카메라·음성·수업을 별도 스레드로 분리해 Gemma가 응답을 만드는 동안에도 영상이 멈추지 않고, 말하는 동안에는 마이크를 꺼서 자기 소리를 질문으로 오인하지 않습니다.
* **빠른 응답:** 한 번 만든 수업은 JSON으로 저장해 같은 물건은 Gemma 호출 없이 즉시 답합니다.
* **아이 안전:** 칼, 가위 같은 위험한 물건은 사전에서 제외하고, 프롬프트에 무섭거나 위험한 내용을 쓰지 않도록 제한했습니다.

**확장성**

* **사물 추가:** `objects.py`에 COCO 클래스명과 영어/한국어 이름을 한 줄 추가하면 됩니다.
* **장난감 인식 강화:** COCO에는 장난감 종류가 적어서(곰 인형, 공, 연, 원반 정도) 장난감 데이터셋으로 YOLO를 추가 학습하면 블록, 자동차 등으로 확장할 수 있습니다.
* **다른 언어 확장:** Piper 목소리와 프롬프트의 언어만 바꾸면 중국어, 일본어 등 다른 언어 학습으로 확장할 수 있습니다.
* **이미지 직접 입력:** 수업 노트북의 `mmproj` 멀티모달 방식을 연결하면 YOLO 사전에 없는 물건도 Gemma가 이미지를 보고 설명하도록 확장할 수 있습니다.

**기타 창의성 및 확장성 내용**

* **발음 피드백(향후):** 현재는 "따라 해 볼까요?"까지 안내하며, 아이가 따라 말한 소리를 Whisper로 인식해 단어와 비교하는 발음 평가를 추가할 수 있습니다.
* **연령별 난이도(향후):** 프롬프트의 문장 길이와 어휘 수준을 설정으로 바꿔 연령에 맞는 수업을 만들 수 있습니다.
* **학습 기록(향후):** 캐시와 질문 이력을 활용해 아이가 배운 단어 목록과 복습 퀴즈를 만들 수 있습니다.
* **노트북 버전:** Jetson 전용 부분(`arecord`, `whisper-cli`, TensorRT)을 파이썬 라이브러리로 바꾼 `english_tutor_laptop` 버전도 함께 만들어 Windows/Mac 노트북에서도 실행할 수 있습니다.
