# Distance & Grab Detector (손과 초록 물체 사이의 거리 측정 및 인터랙션)

Jetson에 연결한 YUYV 카메라 영상에서 **초록색 물체**와 **손(엄지·검지)** 을 각각 인식하고, 둘 사이의 거리를 실시간으로 계산해 선과 숫자로 보여주며, 손이 물체를 집을 만큼 가까워지면 `Grabbed!`를 표시하는 프로젝트입니다.

---

## 파일 구조 (필수)

* `261023project1.py`: 메인 코드. 카메라 입력, 초록 물체 검출, 손 인식, 거리 계산, Grabbed 판정, 화면 출력을 모두 포함
* `hand_landmarker.task`: MediaPipe 손 인식 모델 파일. 처음 실행할 때 `261023project1.py`와 같은 폴더에 자동으로 내려받아지며, 인터넷이 없으면 직접 복사해 넣어야 함
* `README.md`: 프로젝트 설명 문서

---

## 실행 방식 (필수)

**1. 환경**
- NVIDIA Jetson, YUYV 방식 USB 카메라 (`/dev/video0`)
- Python 3, OpenCV (GStreamer 지원), NumPy

**2. 라이브러리 설치 (최초 1회)**
```bash
pip install --no-deps mediapipe
pip install absl-py flatbuffers sounddevice
```
Jetson의 OpenCV가 덮어써지지 않도록 `--no-deps`로 설치합니다.

**3. 실행**
```bash
python3 261023project1.py
```
- 처음 실행하면 `hand_landmarker.task`를 자동으로 내려받습니다. (Jetson이 인터넷에 연결되어 있어야 함. 연결이 없으면 이 파일을 `261023project1.py`와 같은 폴더에 직접 복사)
- 영상 창과 초록색 마스크 창이 함께 뜹니다.
- **종료**: 영상 창을 클릭한 뒤 `q` 키

**4. 조절 가능한 값 (파일 맨 위)**

| 변수 | 의미 |
|---|---|
| `FLIP_CODE` | 영상 뒤집기 (`1` 좌우, `0` 상하, `None` 없음) |
| `GREEN_LOWER`, `GREEN_UPPER` | 초록색 LAB 범위. 물체가 안 잡히면 마스크 창을 보며 조절 |
| `MIN_AREA` | 이 면적보다 작은 덩어리는 노이즈로 무시 |
| `GRAB_RATIO` | 거리가 (물체 반지름 × 이 값)보다 작으면 "가깝다"고 판단 |
| `GRAB_FRAMES`, `RELEASE_FRAMES` | Grabbed 시작/해제에 필요한 연속 프레임 수 |
| `SHOW_MASK` | 마스크 창 표시 여부 |

**5. 화면 표시**
- 파란 원: 초록 물체 (원 크기 = 최소 외접원, 점 = 중심)
- 초록 뼈대와 점: 손 / 빨간 점: 엄지·검지 끝 / 흰 원: 기준점(두 끝의 중점)
- 노란 선: 기준점과 물체 사이 선 (선 중간에 거리 `px` 표시), Grabbed 상태에서는 초록 선
- 왼쪽 위 문구: `Tracking`, `Grabbed!`, `No hand`, `No green object` 등 현재 상태

## 창의성 및 확장성 (프로젝트에만 해당)

### 아이디어 설명

초록색 물체를 손으로 잡는 동작을 컴퓨터가 "거리"로 이해하게 만드는 것이 목표입니다. 손과 물체를 각각 인식한 뒤 두 점 사이의 유클리드 거리를 구해, 선과 숫자로 관계를 시각화하고 일정 거리 안으로 들어오면 "잡았다"는 상호작용(`Grabbed!`)이 일어납니다. 손으로 물건을 집어 옮기는 AR/제스처 인터페이스의 가장 기본이 되는 원리를 직접 구현해 보았습니다.

### 구현한 내용

**1. 초록 물체 검출 (수업의 Color Segmentation, Filtering, Contour 활용)**
- Gaussian Blur로 잔 노이즈를 줄인 뒤, 조명에 비교적 강한 **LAB 색공간**으로 변환하고 `cv2.inRange`로 초록색 영역만 추출
- **Opening**(작은 점 노이즈 제거) → **Closing**(덩어리 안의 구멍 메우기) 순서의 모폴로지 연산 적용
- `cv2.findContours`로 덩어리를 찾고, 최소 면적(`MIN_AREA`)보다 작은 것을 걸러낸 뒤 **가장 큰 contour**를 물체로 선택
- 중심은 **무게중심(Moments)**, 크기는 **최소 외접원(`cv2.minEnclosingCircle`)** 으로 계산

**2. 손 인식 (신체 인식)**
- MediaPipe `HandLandmarker`로 손 관절 21개의 좌표를 구하고, 0~1 비율 좌표에 영상 가로/세로를 곱해 픽셀 좌표로 변환
- 물건을 집는 실제 위치와 가장 비슷한 **엄지 끝(4번)과 검지 끝(8번)의 중점**을 기준점으로 사용

**3. 거리 계산과 시각화**
- `np.linalg.norm`으로 기준점과 물체 중심 사이의 **유클리드 거리** 계산
- `cv2.line`으로 두 점을 잇고, 선의 **중간 지점**에 `cv2.putText`로 거리(px)를 표시

**4. Grabbed 판정 로직**
- 고정 픽셀 임계값 대신 **물체 반지름과의 비율**(`거리 < 반지름 × GRAB_RATIO`)로 판정하여, 손/물체가 카메라에 가깝든 멀든 비슷한 기준으로 동작
- 한 프레임의 판정으로 문구가 깜빡이지 않도록, **연속 N프레임 조건**을 둠. 가까운 상태가 5프레임 연속이면 `Grabbed!`가 켜지고, 멀어진 상태가 5프레임 연속이어야 해제됨 (켤 때와 끌 때 조건을 따로 둔 **히스테리시스** 방식)
- 손이나 물체가 안 보이면 카운터를 초기화하고 상태 문구로 원인(`No hand`, `No green object`)을 표시

**5. 좌표계 일치와 환경 대응**
- 영상 뒤집기는 프레임당 **한 번만** 적용하고, 이후 물체 검출과 손 인식이 **같은 프레임**을 사용하게 하여 두 좌표가 어긋나지 않도록 함
- Jetson의 YUYV 카메라를 GStreamer 파이프라인(`v4l2src`, `YUY2`)으로 연결하고, 지연을 줄이기 위해 `queue leaky`, `appsink drop=true max-buffers=1` 설정을 사용
- 한글이 포함된 경로에서 MediaPipe가 모델 파일을 못 여는 문제를 피하기 위해, 파일 경로 대신 **파일 내용을 읽어서(buffer) 전달**하도록 구현
- 모델 파일이 없으면 자동으로 내려받아 사용자가 따로 준비하지 않아도 되도록 함

### 확장성

아래는 현재 구현에 포함되지 않았지만, 같은 구조 위에 추가할 수 있는 확장 방향입니다.

- **칼만 필터 도입**: 손으로 물체를 쥐면 초록색이 가려져 검출이 끊기고, 이때 `No green object`로 바뀌며 Grabbed가 풀리는 한계가 있습니다. 칼만 필터(`cv2.KalmanFilter`, 상태 `[x, y, vx, vy]`)를 붙여 가려진 동안에는 예측만 수행하면, 가려져도 거리 계산과 Grabbed 상태를 이어갈 수 있습니다.
- **Image Enhancement 추가**: 색 검출 전에 CLAHE를 적용해 조명 변화에 더 강하게 만들 수 있습니다.
- **거리 단위 환산**: 물체의 실제 지름을 알고 있다면 픽셀 거리를 cm로 환산해 표시할 수 있습니다.
- **여러 물체/여러 손**: 현재는 가장 큰 초록 덩어리 1개와 손 1개만 다루지만, 여러 개를 구분해 각각 거리를 계산하도록 확장할 수 있습니다.

### 기타 창의성 및 확장성 내용

- 거리 값에 따라 선 색을 연속적으로 바꾸거나(멀면 파랑 → 가까우면 빨강), 물체와 손의 최근 이동 경로를 꼬리선으로 그리는 등 시각 표현을 풍부하게 만들 수 있습니다.
- "잡힌" 물체를 손을 따라 움직이는 가상 오브젝트로 바꾸면 간단한 AR 인터랙션 데모로 발전시킬 수 있습니다.
- Grabbed 신호를 로봇팔, LED, 소리 등 외부 장치 제어의 입력으로 연결하면 Jetson의 활용 범위를 넓힐 수 있습니다.
